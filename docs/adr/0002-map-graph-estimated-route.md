# 0002. 맵 그래프 경로는 최종적으로 추정 경로를 쓴다

- 상태: 제안
- 날짜: 2026-11-09
- 관련 이슈: #6
- 영향받는 모듈: 그림 로직(`:art`), 화면(`:app`), 차량 데이터(`:vehicle`)
- 결정한 사람: KimYeongBean

## 맥락
맵 그래프는 주행 경로를 그려야 하는데, 위치 신호는 불확실합니다. FusedLocation은 공식 문서 두 곳에 '준비 중'으로 표기되어 있고, 에뮬레이터 수신도 미확인입니다(노션 운영 Q15). 공식 문서에는 위치를 움직이는 시뮬레이션 도구도 보이지 않습니다(ADR 0001).
검토한 선택지:
1. 위치(GPS) 좌표로 경로를 그린다.
2. 속도와 조향각으로 경로를 추정해서 그린다(추측 항법).

## 결정
- 기획안과 최종 구현은 2번(추정 경로)으로 한다.
- 11-13 기능 동결까지의 첫 제출은 1번으로 간다. 샘플에 위치가 있을 때만 경로를 그리고, 없으면 "경로 정보 없음"을 표시한다. 가짜 주행 데이터에는 위치를 넣는다.

## 결과
- 좋아지는 점: 최종 앱은 위치 권한과 위치 SDK 없이도 맵 그래프를 그린다. 실제 위치를 저장하거나 보여 주지 않아도 되어 개인정보 부담이 줄어든다. 차량 신호만 쓰므로 차량특화성 설명에도 유리하다.
- 감수하는 점: 추정 경로는 실제 도로 모양과 오차가 쌓인다. 레이싱 트랙처럼 보이는 그림이라 정확도보다 모양을 우선한다.
- 남은 확인: 조향각 권한·에뮬 수신(노션 개발 §4 '권한 미확인'). 추정 계산은 `:art`의 순수 로직으로 넣어 JVM 테스트로 검증한다.
