# 모듈 인터페이스

모듈 사이에 **무엇을 주고받는지** 적는 문서입니다. 모듈 안쪽 구현은 적지 않습니다.

> **이 파일이 바뀌면(또는 바꿔야 하면) 코딩을 멈추고 먼저 합의합니다.**
> 이슈를 열고 영향받는 모듈 소유자와 전역관리자(@KimYeongBean)가 합의한 뒤 이 파일을 고치는 PR을 먼저 merge합니다. 큰 변경은 [ADR](adr/README.md)로 남깁니다.
> 예외: 기존 내용을 바꾸지 않고 **더하기만** 하는 변경(예: 출력 하나 추가)은 전역관리자가 승인하면 구현 PR에 함께 넣어도 됩니다. 이때도 아래 변경 기록에 행을 남깁니다.

아래는 합의한 **계약 내용**입니다. 패키지는 `io.github.kimyeongbean.iter.<모듈>`로 정했습니다(#8). 실제 클래스·함수 이름은 이 문서에 적지 않고, 구현 PR에서 [GLOSSARY.md](../GLOSSARY.md)의 "코드에서 쓰는 이름" 칸에 채웁니다.
용어는 [GLOSSARY.md](../GLOSSARY.md)를 따릅니다.

## 칸 채우는 법
각 구역마다 아래 항목을 채웁니다. 모르면 `TBD`로 둡니다.
- **입력**: 다른 모듈에서 받는 것
- **출력**: 다른 모듈에 주는 것
- **위치**: 파일/패키지 경로
- **데이터 모양**: 필드 이름·타입·단위 (예: 속도 단위 km/h 여부)
- **다른 모듈이 바꾸면 안 되는 것**: 소유자 합의 없이 고치면 안 되는 부분

---

모듈은 [ownership.md](ownership.md)의 작업 트랙을 따릅니다. 의존 방향: `:app` → `:vehicle`·`:art`·`:model`, `:vehicle` → `:model`(api, 기록 저장소가 공유 타입을 그대로 내보냄), `:art` → `:model`. `:art`와 `:model`은 Android·Pleos SDK에 의존하지 않습니다.

## 공통 상수
| 이름 | 값 | 쓰는 곳 | 비고 |
|---|---|---|---|
| 샘플 간격 | 1초 | `:vehicle`, `:art` | |
| 속도색 최대 속도 | 120 km/h | `:art` | 이 속도 이상은 가장 진한 색 |
| 주행 세션 종료 대기 | 60초 | `:vehicle` | 제안값. P·속도 0이 이만큼 이어지면 종료. 에뮬에서 조정 |
| 최소 Android API | 28 | 전체 | 공모전 개발 환경 안내 기준 |
| 속도색 기본 색 | 기본 테마: 고정 팔레트 5색 중 선택. 다른 테마: 테마가 정한 한 가지 색 | `:art`, `:app` | 테마의 바탕마다 대비 확인. 색 값은 화면 트랙이 정함. `:art`에는 지금처럼 `:app`이 색 하나를 넘김(테마를 알지 못함) |

## 0. 공유 타입 (`:model`)
- 소유자: 통합 / 공통 (여기를 바꾸면 이 문서를 바꾸는 것과 같음)
- 입력: 없음
- 출력: 주행 세션, 샘플 타입. 모든 모듈이 씀
- 위치: `:model` 모듈. 패키지 `io.github.kimyeongbean.iter.model`
- 데이터 모양:
  - **주행 세션**: 시작 시각, 종료 시각(진행 중이면 없음), 출처(실제 차량 / 가짜 주행 데이터), 샘플 목록. 하루 기록 날짜 = 시작 시각의 기기 현지 날짜
  - **샘플** (1초마다 1개):

    | 항목 | 단위·값 | 필수 |
    |---|---|---|
    | 시각 | epoch ms | 필수 |
    | 속도 | km/h, 실수 | 필수 |
    | 깜빡이 | 꺼짐 / 좌 / 우 / 비상 | 없으면 null |
    | 와이퍼 | 켜짐 / 꺼짐 | 없으면 null |
    | 전조등(로우빔) | 켜짐 / 꺼짐 | 없으면 null |
    | 조향각 | 도 | 없으면 null |
    | 브레이크 페달 | 밟음 / 안 밟음 | 없으면 null |
    | 위치 | 위도·경도 | 없으면 null |

  - 위치는 맵 그래프 경로에 씀 (첫 제출, [ADR 0002](adr/0002-map-graph-estimated-route.md)). 조향각·브레이크는 이번 범위 화면에서 쓰지 않지만 기록함 (1차 합격 후 추정 경로·이벤트 표시용)
  - **공유 규칙** (#47, 하루 그림과 맵 그래프가 같은 규칙을 쓰도록 한 곳에 둠)
    - 하루 기록 주행 순서: 주행 세션은 시작 시각 순, 시작 시각이 같으면 출처 순. 각 주행 세션의 샘플은 시각 순. 입력 순서와 상관없이 같은 결과
    - 깜빡이 켜짐: 좌 / 우 / 비상이면 켜짐. 꺼짐과 신호 없음(null)은 꺼짐
- 다른 모듈이 바꾸면 안 되는 것: 항목 이름·단위·null 허용 여부 전부, 공유 규칙

## 1. 차량 데이터 (`:vehicle`)
- 소유자: TBD ([ownership.md](ownership.md))
- 입력: Pleos Vehicle SDK·AAOS 차량 신호, 위치(가능할 때)
- 출력:
  - **기록 저장소** — 주행 세션 저장, 날짜별 하루 기록(그날 주행 세션 목록) 조회, 기록이 있는 날짜 목록 조회, 모두 지우기(디버그 메뉴의 기록 초기화용)
  - **주행 세션 기록기** — 차량 신호 흐름으로 주행 세션을 감지해 기록 저장소에 저장. 진행 중인 주행 세션 여부, 주행 중 여부(진행 중 주행 세션이 있거나 기어가 P가 아님. 기어 신호가 없으면 주행 중 아님. 화면의 "기록 중" 표시용), 수동 시작·끝 요청을 받는 입구(기어 D에서 수동 끝을 받으면 D를 벗어날 때까지 자동 시작 안 함), 실제 차량 신호로 기록을 시작하는 입구(화면이 런타임 권한을 물은 뒤 부름. 권한이 없는 신호는 없음(null)으로, 차속은 0으로 기록)
- 위치: `:vehicle` 모듈. 패키지 `io.github.kimyeongbean.iter.vehicle`
- 데이터 모양: 0번 공유 타입
- 다른 모듈이 바꾸면 안 되는 것: 기록 저장소가 실제 기록과 가짜 주행 데이터를 **같은 방식으로** 저장·조회한다는 점 ([ADR 0001](adr/0001-fake-drive-data-via-record-store.md))
- 메모: 진행 중 여부는 기록기의 실행 상태 기준. 앱이 비정상 종료되면 저장소에는 종료 시각 없는 주행 세션이 남지만, 다음 기록 시작 때 마지막 샘플 시각으로 닫힘 (#16)

## 2. 그림 로직 (`:art`)
- 소유자: TBD
- 입력: 하루 기록(주행 세션 목록), 사용자가 고른 속도색 기본 색
- 출력:
  - **그림 데이터**: 하루 그림을 그리는 데 필요한 도형 목록(각도, 반지름, 색, 무늬). 그리는 일은 하지 않음. 저장하지 않고 필요할 때 계산
  - 그림 데이터의 도형은 **주행 시간 순서**로 나열하고, 도형마다 하루 기록 안의 **시간 위치(0~1)**를 가짐. 화면의 '그려지기' 애니메이션이 이 값으로 진행도를 정함
  - 속도 → 속도색 계산
  - (1차 합격 후) 샘플의 속도·조향각 → 추정 경로
  - **가짜 주행 데이터**: 완성된 주행 세션 묶음 (정상 / 급가속·급제동 / 신호 일부 누락, 여러 날짜)
- 위치: `:art` 모듈 (순수 Kotlin/JVM). 패키지 `io.github.kimyeongbean.iter.art`
- 데이터 모양: **그림 데이터** = 도형 목록 (#12)
  - 하루 기록의 샘플을 주행 세션 시작 순·시각 순으로 이어 붙여 원 둘레(12시 방향에서 시계 방향, 360도)에 고르게 나눔. 위치는 쓰지 않음
  - 도형 하나 = 연속한 샘플 구간. 도형은 최대 120개(샘플이 더 많으면 묶음)
  - 도형 필드: 시간 위치(0~1, 구간 시작), 시작 각도·각도 폭(도), 안쪽·바깥 반지름(그림 반지름 대비 0~1), 색(ARGB, 구간 평균 속도의 속도색), 무늬(깜빡이 / 와이퍼 / 전조등 중 켜진 것. null 신호는 무늬 없음)
  - 바깥 반지름은 0.25~0.85 (속도 비례, 속도색 최대 속도에서 0.85). 0.25 안쪽과 0.85 바깥은 화면이 무늬를 그리는 자리
  - 빈 하루 기록이면 도형 없음
- 다른 모듈이 바꾸면 안 되는 것: 같은 입력이면 같은 그림 데이터가 나옴(결정적). 잔디 축소본과 큰 화면이 같은 결과를 씀. 도형의 시간 순서·시간 위치

## 3. 화면 (`:app`)
- 소유자: TBD
- 입력: 1번 기록 저장소, 2번 그림 데이터·속도색
- 출력: 화면 (맵 그래프, 하루 그림, 잔디), 디버그 메뉴 "가짜 기록 넣기"(2번 가짜 주행 데이터를 1번 기록 저장소에 저장)
- 위치: `:app` 모듈. 패키지 `io.github.kimyeongbean.iter.app`, applicationId `io.github.kimyeongbean.iter`
- 데이터 모양: 없음 (다른 모듈에 주는 것 없음)
- 다른 모듈이 바꾸면 안 되는 것: 빌드 설정·매니페스트·권한 선언 (다른 트랙은 요청만)
- 메모: 주행 중(1번 주행 중 여부)에는 "기록 중" 상태만 표시. 맵 그래프·하루 그림·잔디는 주행 중이 아닐 때만 열림
- 메모: 애니메이션은 정차 화면에서만. 기어 D가 되면 진행 중 연출을 즉시 멈춤. 연출 중에는 그림 데이터·경로 좌표를 다시 계산하지 않고 미리 계산한 값을 그림 (기준: 노션 디자인 '애니메이션·전환 기준'). 반복 연출은 그날 화면의 그림 칸 안에서만: 와이퍼 구간 표시(비 효과)와 고급 테마마다 하나 (#87)
- 메모: 테마는 사용자가 설정에서 고름. 단색 테마는 그림 칸의 바탕색·선 색만, 고급 테마는 그리는 방식과 화면 전체 색(라이트·다크)·바탕 무늬까지 정함. 모두 `:app` 안에서 처리하고, 2번 그림 데이터는 테마와 상관없이 같음. 고급 테마는 도형의 색 대신 바깥 반지름에서 속도를 읽어 테마의 색으로 그림 (#87)
- 메모: 맵 그래프는 지도 배경 없이 경로만 그림. 바탕과 그리는 방식은 테마가 정함(기본 테마는 바탕을 어두운/밝은 중 사용자가 고름). 첫 제출은 샘플에 위치가 있을 때만 그리고, 없으면 "경로 정보 없음" 표시. 최종은 추정 경로 ([ADR 0002](adr/0002-map-graph-estimated-route.md))

트랙 구분을 바꿀 때도 위의 합의 절차를 따릅니다.
